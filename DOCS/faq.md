# Preguntas Frecuentes (FAQ) — Catálogo Pro

## 1. ¿Qué es Catálogo Pro?

Catálogo Pro es una aplicación web que permite a los usuarios consultar un catálogo de productos tecnológicos, conocer sus precios y seleccionar los productos que desean comprar.

## 2. ¿Cómo puedo encontrar un producto?

El usuario puede explorar el catálogo, seleccionar una categoría o utilizar la barra de búsqueda para encontrar el producto que necesita.

## 3. ¿Cómo funciona el carrito de compras?

El carrito permite agregar productos, aumentar o disminuir las cantidades y revisar el subtotal de la compra. También permite verificar el total antes de continuar con el proceso de compra.

## 4. ¿Cómo puedo revisar el total de mi compra?

El usuario puede ingresar al carrito para consultar los productos seleccionados, sus cantidades y los importes correspondientes. Si el sistema aplica el IVA, este se incluye en el cálculo del total.
